### Что изменилось
* **Текстуры** (`out/textures/`, 14 наборов × BaseColor / Normal / ORM + две плоские константы, 1024 px, PaintWorn 512 px, всего 50 МБ PNG): окрашенные композитные панели (кремовые снаружи, тёплый серо-бежевый внутри) с крепежом, лёгкой грязью и потёками; шлифованный анодированный металл «петроль»; тёмный рифлёный резиновый пол с монетными шипами; светлая композитная плитка; перфорированный потолок; бетон площадки с трещинами и пылью; кровельная мембрана со стоячими швами; фотоэлементы с шинами; ткань сидений; вязаное одеяло в полоску; дубовый ламинат; **экранный фон** (эмиссия: глубокий бирюзовый с циановой сеткой, поверх — прежняя геометрия интерфейса). Палитра одна: кремовый, петроль, сланцево-бирюзовый, насыщенный бирюзовый акцент, янтарь/ржавый оранжевый, дерево, песочный бетон. Нормали — **DirectX** (родной формат Unreal, зелёный не переворачивать); в Blender-материалах зелёный переворачивается.
* **UV:** канал 0, коробочная проекция в **метрах** по доминирующей оси нормали, у каждой панели / плитки / предмета свой случайный (детерминированный) сдвиг, чтобы повторы не совпадали; `1 / tile` = тайлинг материала (таблица тайлов в README и `HQ_Spec.json`). У `HQ_Solar` и `HQ_ScreenFace` — явные UV 0..1 на каждый квад. Проверка после FBX: плотность 0,81–1,0 UV на метр на всех слотах, вырожденных UV-треугольников нет.
* **Материалы Blender:** Principled с картинками (база × тонировка, нормаль DX→GL, ORM), плоская палитра осталась запасной; слоты те же + **6 новых**: `HQ_Teal`, `HQ_Fabric`, `HQ_Blanket`, `HQ_Wood`, `HQ_ScreenFace`, `HQ_Plastic`.
* **Формы** (`scripts/hq_shapes.py`: скруглённые боксы 2/4 сегмента, токарные тела, трубы, скруглённые выдавливания, наклонные рамки, плавные нормали): **кресла** (пятилучевая база с колёсиками, газлифт, продавленное тканевое сиденье, изогнутая спинка с поясничным выступом, подлокотники; **теперь они смотрят на консоли — в v1 спинка была повёрнута к консоли**), **консоли** (скруглённый профиль, наклонная панель с сенсорным дисплеем, кнопки, джойстик, подставка под запястья, два изогнутых монитора на стойках со светодиодами статуса), **настенные дисплеи** (скруглённая рамка, текстурированный экран, светодиоды, полка), **шкафчики шлюза** (бирюзовые дверцы, жалюзи, рёбра, ручки-планки, номерки), **двухъярусные койки** (трубчатые стойки, рамы, матрас, одеяло, подушка, лесенка, ограждение, лампа), **кухонный блок** (фасады с ручками, деревянная столешница, мойка с краном, варочная панель, навесные шкафы с подсветкой), шкаф, **стеллажи склада** (скруглённые стойки, полки с бортиком, цветные ящики с бирками), климат-блоки (вентиляторы с лопастями и решёткой, жалюзи), солнечные стойки, болларды, обрамления дверей (двухступенчатые), рамы окон, линзы потолочных светильников, парапеты, плитка пола (с фаской), стеновые и потолочные панели (приподнятый кант и утопленное поле с фаской), бирюзовая полоса на всех внутренних стенах.
