## Узкая оптимизация collision sampling

В изолированном build host добавлен bounded ParallelFor (максимум4задачи),
без изменения размеров коллизии, шума, позиций, треугольников или частот рельефа.
Массивы выделяются до запуска; каждая задача пишет только собственный индекс.
Все задачи завершаются до публикации mesh/возврата из функции. Это параллельный
join, не готовая асинхронная очередь/кадровый бюджет.

Только root с tag `APS.Collision.ParallelSamples`; проект ставит его собственному
точному native-классу UAPSWorldScapePlanetNoise в full-scale, без preview/manual.
При heightmap/noise/hole volumes путь serial. CVar `worldscape.CollisionSampleTasks 1`
возвращает последовательный расчёт, 4 — кандидат. Не менялись public headers,
ABI, worker fence, материалы, нормали, география, навигация или корабли.

Private тесты3/3: CollisionSamplingParity (33552вершины, serial/parallel/untagged,
сфера/плоскость,17/65resolution,2позиции), WorkerCompletionOwnership,
LodGeneratedSewingNormals. Это не измерение FPS и не визуальная приёмка.
В первом incremental build новый test не попал в cached makefile; повторный
NoUBTMakefiles собрал test TU, и отчёт действительно содержит все три теста.
