## Внесённые изменения

1. **Выбор семьи:** удалён ранний выход после первого подходящего элемента TMap.
   Сравниваются все допустимые семьи по расстоянию до поверхности. Вместо абсолютной
   блокировки resident-core сохранён мягкий приоритет текущей семьи 0.72; текущего
   тела — 0.8. Равные оценки сохраняют текущий объект, иначе сравнивают полный путь.
   Preload/unload и activation/deactivation радиусы не менялись. NaN/Infinity и
   недопустимые радиусы не могут выиграть выбор.
2. **Газовые спутники:** единый SupportsWorldScape-фильтр для планет и лун.
   Газовая луна больше не занимает active slot без возможной поверхности; твёрдая
   луна газового гиганта остаётся допустимой. Живое solid -> gas изменение вызывает
   штатную, ожидающую завершения workers выгрузку прежнего root.
3. **Повторное сканирование геометрии:** полные проверки terrain/ocean payload
   выполняются только до первой публикации поверхности и только без workers.
   Готовая поверхность сохраняет latch. Защита жидкой оболочки от коллизии/теней
   продолжает обновляться; запрет чтения worker-owned массивов сохранён.
4. **Плоские участки:** начальная проверка сравнивает рельеф с ожидаемым шумом,
   вместо безусловного требования перепада >= 1 m. Реальная плоская равнина/дно
   допустимы. Сфера без ожидаемого рельефа, неверный datum, NaN и неполный payload
   по-прежнему отклоняются. Максимальная ошибка высоты остаётся 2.5 m; остальные
   проверки anchor/coverage/топологии не ослаблены.
5. **Вода и спутники:** общий критерий для owned full-scale Water, без ограничения
   классом APlanet. Уже видимые Active/FrozenVisible водные тела обновляют только
   optical MID scalars каждый кадр из кэша weak-ссылок; мировой поиск остаётся 2 Hz.
   Нет новой оболочки, замены шейдера или обхода вершин каждый кадр. Сохранённые
   параметры читаются из родителя, а не накапливаются из предыдущего blend.
   Manual/borrowed/scaled/custom, Lava и Ammonia исключены. Near/disabled восстанавливают
   точные сохранённые scalars; неизменные значения не посылают новые render updates.
6. **Бюджет сетки:** после разбора стоимости Rio явно выбрал 256. Теперь
   MeshResolution по умолчанию 256 (допустимо 96..256), CoastResolution=0 наследует
   эту базу. Generated full-scale планеты и луны, включая сухие, получают 256;
   terrain/ocean согласованы. Ручные roots, preview и collision не изменены.
   Это выбранный тестовый бюджет, ещё не подтверждённый замерами FPS.
7. **Спекулятивная память:** вместо постепенного создания всей семьи держатся до
   четырёх ближайших скрытых, ещё не показанных sibling roots. Существующие тёплые
   заготовки имеют коэффициент 0.8 против дрожания выбора. Максимум две новые
   заготовки за poll; активная планета не ждёт этой квоты. Удаление лишних заготовок
   идёт через штатный worker drain. При незавершённых задачах освобождение не мгновенно.

## Что намеренно не считается закрытым

- **Полный лимит RAM/VRAM посещённой семьи.** MaxStandbyRoots ограничивает только
  непоказанные заготовки. Published FrozenVisible поверхности НЕ удаляются ради
  бюджета: это снова показало бы пустую сферу. Для настоящего ограничения нужен
  проверенный дальний renderer с той же географией/материалом и бесшовной передачей.
  Это отдельный визуальный этап, не безопасная подмена на текущую заглушку.
- **Новые течения и физическая батиметрия.** Изолированные water v22/v23 не перенесены
  в production: собственные визуальные дефекты и moving A/B/A ещё не закрыты.
- Угловатые берега/белёсые края лавы не объявляются исправленными этим lifecycle-аудитом.
  Эмиссия, шум, seed, карта суши, высота моря, бинарные материалы и сохранения не менялись.

## Источники регрессионных тестов

Добавлены (не запускались):

- `APS.Gameplay.World.PlanetSurface.StreamingSelectionPolicy` — все шесть порядков
  кандидатов, невалидные значения, гистерезис, детерминированные равные оценки.
- `APS.Gameplay.World.PlanetSurface.StreamingSelectionAndStandby` — реальный subsystem
  с тестовым pawn/controller: перекрывающиеся семьи, возвращение, газовая луна,
  твёрдая луна гиганта, solid -> gas, repeated polls, standby cap=2/0, сохранение
  опубликованного sibling и штатный выход из семьи. World не тикается; опубликованный
  payload моделируется latch. Это не render/collision acceptance.
- `APS.Gameplay.World.PlanetSurface.InitialPayloadReadiness` — flat/low-relief,
  неверная высота, undisplaced sphere, NaN, неполные samples, published/worker guards.

Расширен `OrbitalWaterAppearance`: eligibility для generated body, исключение
manual/borrowed/scaled/других жидкостей. Ранее добавленные `ResidentResume`,
`LiquidLattice`, `LivingPaletteDetail` также входят в проверочный набор.

## После сборки пользователем

1. Запустить тесты `APS.Gameplay.World.PlanetSurface` и посмотреть не только общий
   счётчик, но и сообщения упавших случаев. Новые тесты ещё не подтверждены компилятором.
2. SinglePlay PEEH и saved BEM: planet -> moon -> planet несколько раз; вертикальный
   спуск, взлёт, смена pilot/pawn, выход из семьи и возврат. Никакой белой сферы
   вместо готового рельефа или возвращения второго пола.
3. Перелёт между близкими семьями: выбирается действительно ближайшая поверхность,
   а не первый элемент или навсегда закреплённая прежняя семья; без дрожания на границе.
4. Water планета И луна: медленный/быстрый проход 200 -> 20 -> 0 km и обратно,
   камера вдоль/поперёк поверхности, сверка берегов/блика/палитры с исходными кадрами.
   Соседняя замороженная водная планета должна обновлять optical response.
5. Rocky/Frozen/Volcanic/Terrestrial плюс Ammonia: начальная поверхность, flat area,
   посадка, возврат; ручной home/preview не меняются. Проверять тени/коллизию отдельно.
6. Одинаковый маршрут и камера: CPU/GPU frame time и RAM/VRAM после нескольких лун
   и выхода из семьи. Не обещать 120 FPS по факту изменения кода.

Настройки: `aps.Surface.MaxStandbyRoots 4` (0 запрещает спекулятивные preloads,
но не активную поверхность); `aps.Surface.MeshResolution 256` и
`aps.Surface.CoastResolution 0` — новые значения по умолчанию. Для возврата к 192:
`aps.Surface.MeshResolution 192` вместе с `aps.Surface.CoastResolution 0` перед
новым PIE. `aps.Surface.OrbitalWaterContrast 0` возвращает saved optics.
`aps.Surface.UnifiedLavaSurface` остаётся 0. Никаких новых baked assets в этом проходе.

Статическая проверка: просмотр diff, сверка API установленного UE/WorldScape,
`git diff --check`. Она не заменяет компиляцию, исполнение тестов или rendered proof.
