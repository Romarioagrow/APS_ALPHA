# Авторские миры: пресеты генератора вместо ручных карт

Claude, 2026-10-09. Идея Rio (09.10): помимо рандомной генерации (сегодняшний основной режим меню) нужны **заданные,
проработанные миры на всех уровнях** — галактика, скопление, система, планета, стартовый вид, — которые всегда
генерируются одинаково (одно зерно), с названием и лором. По сути это наш «сингл»: ручные карты через level
generation больше не нужны, у нас есть целая система генерации — делаем шаблоны. Отдельно от происхождений: мир +
происхождение + режим = запуск.

Что умеет генератор сегодня (проверено по `Core/Model/GeneratedWorld.h`, `Core/Enums/*`, `UI/MainMenu/APSWorldRoll.h`):
галактика — 6 типов и ~40 классов, включая пекулярные (кольцо, полярное кольцо, приливные хвосты, взаимодействующая
пара); скопление — 13 форм (открытое, шаровое, поток, кольцо/дуга, песочные часы, двойное, вложенное…), размеры
Tiny…Colossal; домашняя система — одиночная, двойная, тройная, кратная звезда (`EStarType`), типы звёзд от
коричневого карлика до гипергиганта, нейтронной звезды, пульсара и чёрной дыры (`EStellarType`), тип системы
(многопланетная, одна планета, обитаемая зона, газовые гиганты), распределение орбит; планета — 35 типов
(`EPlanetType`: Terrestrial, Ocean, Archipelago, Pangea, Forest, Savanna, Oasis, Desert, Sand, Tundra, Nordic,
HighMountain, Frozen, Ice, Lava, Volcanic, Basalt, Sulfur, Crystal, Metal, Carbon, GasGiant, IceGiant, HotGiant…),
радиус, пригодность, спутники с собственным типом и пригодностью, орбита спутника, зерно и шкалы поверхности
(рельеф, горы, кратеры, суша, шероховатость); старт — орбита/поверхность планеты, орбита/поверхность луны, корабль.
REGENERATE (`APSWorldRoll`) уже крутит мир по уровням (галактика, скопление, система, звезда, тело) и «время от
времени — ручной архетип»: авторский мир — это такой архетип с закреплённым зерном, именем и картинкой.

## 1. Что такое авторский мир

Запись из трёх частей:
1. **Модель мира** — сериализованная модель меню (`UGeneratedWorld` + явные правки звёзд и тел + зерно), ровно то,
   что сохраняется при сохранении мира: «a rolled world saves, loads and reaches gameplay exactly like an edited
   one». Файл `Content/APS/APS_ALPHA/Worlds/Authored/<id>/world.json`.
2. **Карточка** — `card.json`: имя, подзаголовок, лор (EN, 2–3 предложения), теги, какие уровни **закреплены**
   (галактика / скопление / система / звезда / планета / поверхность), рекомендуемые режимы и происхождения, место
   старта и стартовый вид, версия пресета.
3. **Картинки** — `thumb.png` и 3 кадра (вид со старта, система, планета), снятые генератором в меню.

Замки — это уровни `APSWorldRoll::EScope`: закреплённый уровень REGENERATE не трогает, открытый — крутит. Так
авторский мир может быть «та же планета и система, а галактику и скопление крути как хочешь», или наоборот.

## 2. UX

**Вход.** NEW WORLD → карточка **AUTHORED WORLDS** (это место карточки SINGLE GAME из плана меню «Обсерватория»:
«авторские карты, выбор из списка» — ручные карты заменяются пресетами; старая `L_APS_SinglePlay_StartLocation`
остаётся в списке как нулевой пресет THE FIRST STATION). Рядом — **RANDOM** (сегодняшний путь, как есть).

**Галерея.** Крупные карточки: кадр со старта, имя, подзаголовок, три тега (например `BINARY · SAVANNA · ANCIENTS`),
значки режимов (ORIGIN / SANDBOX / TRIPS), рекомендуемое происхождение, число закреплённых уровней. Сортировка:
рекомендованные → по тегам. Hover — три кадра.

**Выбор.** Открывается обычный экран генерации с загруженным пресетом: закреплённые поля с замком, у REGENERATE
активны только открытые уровни, кнопка RESET TO AUTHORED. Дальше — выбор пути как сейчас (CIVILIZATION с пресетом
режима / SPACE / PLANET). Мир с замками на всех уровнях — просто «нажми GENERATE».

**Связь с остальным.** Происхождение выбирается на экране CIVILIZATION как обычно; карточка мира лишь
рекомендует. SPACE TRIPS берёт авторские миры как готовые направления (маршрут «AUTHORED WORLDS TOUR»). Коды
поездок и WORLD CODE (roadmap 04.10) совместимы: авторский мир — именованный код.

**Как мы их делаем.** В меню крутим и правим, пока мир не совпадёт с концептом → сохраняем мир → консольная команда
`aps.Worlds.ExportAuthored <id>` пишет `world.json` + снимает кадры → карточка руками → офскрин-проверка (кадры на
трёх уровнях + старт на поверхности, FPS против базы) → Rio смотрит в игре. Золотой тест на каждый пресет:
генерация даёт тот же состав (звёзды, число и типы планет, имя и тип домашнего мира), чтобы правки генератора не
ломали авторские миры молча.

Для каждого: концепт, уровни (поля генератора), стартовый вид, лор (EN для карточки), связь с цивилизацией и
происхождениями, что нужно сверх того, что есть. ✔ — собирается сегодняшним генератором; ⚠ — нужна отмеченная
возможность.

## 5. Смысл и сюжет (на потом, решение Rio)

Три варианта, не исключающие друг друга: (а) общий смысл для всех — Дорога Строителей, как в ORIGIN; (б) у каждого
мира своя короткая цепочка на 3–5 шагов, вытекающая из его природы (TWO SUNS — «тихий час», THE WELL — линза, THE
STREAM — вверх по течению, EMBER — «успеть»); (в) лор только в карточке и журнале первой минуты, без квестов.
Предлагаю (а) сразу (ничего не стоит) + (б) по одному миру за раз после раннего доступа.

## 6. Код (карточка T-21 в ORIGIN_TASK_CARDS)

- Загрузчик пресета: `world.json` → модель меню тем же путём, что загрузка сохранённого мира; замки по
  `APSWorldRoll::EScope`; RESET TO AUTHORED; id и версия пресета — в хеш манифеста.

- Галерея AUTHORED WORLDS на экране NEW WORLD (общая зона меню, handoff).
- Золотые тесты `APS.Worlds.Authored.<id>`: состав мира совпадает с сохранённым описанием.
- Ручки пресета сверх генератора: гарантированный сосед заданного типа (W3), плотность сайтов Древних (W6),
  множители правил (SolarArray ×1,5 в W2) — поля карточки, читаются при старте.
