## 1. Как не потратить бюджет

1. **Исполнитель не исследует код.** Карточка — единственная спека: файлы, функции, выключатель, тесты. Запрет на
   поисковых агентов; одна проверка функции по имени — и писать. Описи и инвентари уже сделаны.
2. **Fable — только на пять опасных мест:** старт ARK (T-05), ДОЛГОЕ ПАДЕНИЕ (T-14), загрузчик и замки авторских
   миров (T-21), спайк реального неба (T-22), интеграционная сборка каждой волны. Всё остальное — обычная модель по
   карточке.
3. **Один билд на волну, ночью.** Проверка карточки — автотесты без мира + cl-check; офскрин-перф-A/B — один на волну,
   не на карточку. Днём играет Rio: его время вместо наших повторных прогонов.
4. **Код не ждёт арт.** Все пути к ассетам — в каталогах (колония, инфраструктура, корабли), заглушки сегодня
   (ковчег = `S_P3_01`, модули = примитивы, мёртвая станция = `AI_Stations\03`), подмена на A-00 / кит / станцию —
   без правок кода, когда Codex отдаст.
5. **Всё по умолчанию выключено.** Один мастер-выключатель `aps.Origin.All` включает весь набор для теста Rio;
   SANDBOX без него совпадает с сегодняшним байт в байт (тест на хеш манифеста).
6. **Решения — по дефолтам сейчас** (§4), чтобы ни одна сессия не ждала ответа.

## 5. Что гарантирует «без косяков»

- Каждая карточка: тесты без мира обязательны; без них карточка не считается сделанной.
- Хеш манифеста SANDBOX = сегодняшний — автотест в волне 1; любое расхождение = стоп.
- Форматы сейвов не меняются ни в одной карточке (всё через `Unlocked`, миссии, SpawnParameters, свои файлы).
- Общие зоны — по одной сессии на зону за волну; остальные сессии их не открывают.
- Один перф-A/B на волну против базы `runs/p1-far-h`; правило «не навредить» — проверка кадров до/после.
- Rio играет один раз на волну; найденное чинится в начале следующей волны, не отдельными прогонами.
