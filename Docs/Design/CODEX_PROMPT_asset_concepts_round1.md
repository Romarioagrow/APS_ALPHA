Правила картинок (кратко, подробно в §0.2 и §0.5 брифов):
- Один объект на картинку, ракурс три четверти спереди-слева, чуть сверху; объект по центру, ~80 % кадра; ровный
  серый фон #808080; студийный свет; без текста, людей, земли, неба, подписей масштаба.
- Стекло непрозрачное тёмное. Тонкие тросы, антенны-иглы, сетки, провода не рисовать.
- Все части соединены, ничего не висит; симметрия, где естественна.
- PNG 1536×1536 (минимум 1024).
- Стили из манифеста (`styles`): `aps` — белая эмаль + один оранжевый акцент + тёмная сталь + сотовые решётки,
  без неона и teal; `builders` — чёрный гранёный камень, тил-белые светящиеся швы, ничего круглого кроме колец,
  никакой техники; `expedition` — тот же `aps`, но постаревший: серая выцветшая эмаль, нагар, пыль, красные
  аварийные лампы; `none` — природный объект без стилевой привязки.
- Промт собирать из `visual_en` + описания стиля + масштаба из `dimensions_m` (словами, например «a 9 m long
  module»). Негатив: `text, watermark, people, background scenery, transparent glass, thin wires, cables,
  floating parts, multiple objects`.
- Для орбитального кита: сначала сгенерировать ядро O-00, выбрать лучший вариант самому и держать его в кадре
  (как часть сборки) у всех навесок O-01…O-10 для консистентности. Для китов C-*, ST-* — один и тот же
  image-reference эталона у всей партии.
- kind `object` — 3 варианта (v1, v2, v3). kind `object_set` с полем `count` — по 3 варианта на каждый из `count`
  объектов (E-04 → 5 астероидов, E-07 → 3 обломка), подпапки `<id>_<n>`. kind `reference` (H-01, I-01) — 3–4
  mood-картинки без требований к ракурсу и фону.
- Варианты должны реально различаться (пропорции, компоновка), а не быть одной картинкой с другим сидом.
